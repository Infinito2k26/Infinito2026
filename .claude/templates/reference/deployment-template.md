### Staging

```bash

```

Steps:
1. CI passes (lint, typecheck, build, tests).
2. Build artifacts pushed.
3. Migrations run: `<migrate command>`.
4. Service restarts.
5. Health check passes.

### Production

```bash

```

## Rollback Procedure

1. Identify the last known good deployment (tag or commit).
2. Redeploy that version: `<redeploy command>`.
3. If a migration was applied, run the reverse migration: `<rollback command>`.
4. Verify health check passes.
5. Open a post-mortem issue in GitHub.
